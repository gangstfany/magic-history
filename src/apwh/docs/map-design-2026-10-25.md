# 世界史因果链与练习地图

依据用户指定的 Hoyuwon/USH_1019 main（0eea622）交互框架，在现有离线世界史预览中实现；不推送 GitHub。

- 因果链：只显示当前链，地图与右侧面板统一用步骤序号。箭头只连接相邻且已定位的步骤；不把因果线沿途经过的国家当作相关地区。当前步骤用圆环强调，不引入老鹰或其他国家象征。重复或邻近地点错开节点，用细线回指实际坐标。点击节点及右侧步骤双向同步；切换步骤保持镜头，重置按钮重新框定当前链。
- 练习：答题前隐藏所有复习标注，判分后显示本题实际地点、原题事件摘要、年份与主题。沿用原始内容，不新增历史结论。练习模式隐藏学习时间线和悬浮地区标签；地图交互不会打开学习卡。下一题、退出及模式切换清空说明。
- 避让：按实际 DOM 尺寸放置说明，保护所有着色地理轮廓的完整包围盒、地点标记、缩放按钮和地图边界。无安全位置或宽度不足620px时，将说明移到地图下方；宿主页自动重新测量 iframe 高度。节点至少48px分离，触控区域44px。

实现：map-layout.cjs 提供纯几何函数；map-enhancements.js/css 管理地图覆盖层和说明栏；enhance_maps.py 以断言保护原始源码插入点，build.py 生成自包含双层页面。

验证：几何单元测试、所有原有链条三种尺寸的节点布局、脚本语法、240张已审查学习卡回归；浏览器检查四种题型、地图与侧栏联动、切题清理、九单元和319/390px宽度。

## 跟随式动画（第二轮）

用户指出全链同时显示仍不清晰，要求图标从1移动到2，停在2所在地图位置，并弹出相关地点、事件。

- 中性圆点沿当前相邻段移动约1.5秒，随后镜头定位约0.65秒；抵达后只保留当前节点并显示说明。
- 说明使用该环原有证据与上一环的因果连接，避免按城市任取历史事件。较长证据可展开，地图内说明高度固定且可滚动，避免展开后越界。
- 自动播放每站停留5.5秒；地图上和右侧均有播放控制。途中暂停冻结图标与镜头，继续后完成剩余动画。手动点击不相邻步骤直接定位，避免制造跨环的因果连线。
- 查看全链/聚焦本站可切换；还原按钮显示全链。切换链条或进入其他模式会取消旧动画，旧站点不会延迟弹出。
- 继续保留地区/标记/控件避让及窄屏说明栏；减少动态效果时直接定位并展示说明。

实现：causal-journey.cjs 为可测试的动画时钟和步骤数据选择；causal-map-journey.js 管理镜头、播放节奏与抵达说明。验证暂停/继续、镜头阶段、取消、减少动态效果、所有链条证据完整性，以及浏览器从1到2和自动抵达3、4。
