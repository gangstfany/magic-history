# 因果链模块：静态点选与商路整合

本轮按用户要求移除因果链动画。因果环节点选后直接定位地图，显示地点、证据及因果解释；保留静态全链概览和上一环／下一环。删除旧动画渲染文件，商路自身的运输演示仍保留。

因果链模块内分为“因果推演”和“商路与交流”。只在明确关联的环节显示商路入口及关联理由，关系由 causal-trade-links.json 管理，不自动将同一单元所有商路视为因果证据。

展开商路时保留链 ID、环节、Unit、地图镜头、概览状态和阅读位置。商路面板及地图卡片均提供返回入口。浏览目录中的其他网络时标记“自由浏览”，返回点不变。商路目录展示全部六张网络图，并保留不同交流类型的说明。

因果环列表使用紧凑布局，仅模块切换及商路返回提示固定，避免标题遮挡环节点选。新增组件样式同时注入宿主页面和地图 iframe，防止镜像面板出现浏览器默认按钮样式。

验证覆盖：纯函数及生成页面测试、240 张学习卡与 18 张单元卡内容验证；浏览器检查 Unit 2 第 3 环与印度洋网络往返、自由浏览返回、全链概览和移动宽度布局。本地预览，无 GitHub 推送。
