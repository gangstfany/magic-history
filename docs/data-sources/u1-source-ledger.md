# Unit 1 source ledger: Global Prehistory

This ledger freezes the media-selection and attribution record for the official AP #1–11 sequence. The identification column is transcribed against the current College Board CED (rev. 09/2025), Unit 1 listing: title, provenance, date, and medium. The study column deliberately joins the supplied `APAH notes.pdf`, `1.Prehistoric Art.pdf`, and *Smarthistory Guide to AP Art History, Volume One* with the relevant Smarthistory work essay. Direct-image links are browser-resolvable Wikimedia `Special:Redirect/file` endpoints; each was opened with its source page during this audit.
