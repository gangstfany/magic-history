# 公共首页与独立课程模块

用户要求：首页成为可嵌入世界史、美国史、欧洲史、艺术史的公共外壳，课程彼此独立。

采用静态页面加 iframe 隔离，沿用现有技术与课程实现。相比将课程全部改写成组件，这种方式能保留已审查的课程功能；相比只拆分 Git 分支，它真正隔离运行时与源码。

- 公共首页负责品牌、导航、账号、课程列表、加载提示、重试、独立打开与 URL 课程选择。
- 课程注册表声明入口和是否上线，首页不读取课程内部 DOM 或私有 API。
- 世界史工作区移到 apwh.html，源码在 src/apwh/workspace.template.html，保留 Today’s Pick、学习卡、地图、因果链、商路与练习。
- 美国史使用 apush-map.html；艺术史使用 art-history-map.html?embed=1；欧洲史暂无内容，显示独立的待上线状态。现有课程内容不改写。
- 切换课程保留已经加载的 iframe，账号弹窗仅存在于外层首页。课程独立打开也能工作。
- 课程桥接脚本仅报告 ready 和内容高度；父页面核对 origin、source、课程 ID 及消息数据。艺术史保留自己的地图和详情尺寸，嵌入时 body 使用自然高度，由同一契约上报完整内容高度。
- 构建世界史只写世界史产物；构建公共壳不依赖世界史数据。统一脚本可依次构建两者。
- 现有静态链接继续可用；旧首页链接仍进入公共首页。完整网站仍统一部署一个静态目录。

验证：公共模块协议单元测试，原世界史内容和工作区回归测试，账号34项测试；桌面与手机浏览器验证课程切换、保留状态、深链接、未上线与失败重试、账号弹窗及世界史学习流程。

本次在 feature/modular-site-shell 工作，不自动合并 main 或其他课程分支。
