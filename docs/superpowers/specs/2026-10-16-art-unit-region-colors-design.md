# 艺术史地图：按 Unit 高亮分区（B 方案）

日期：2026-10-16

状态：用户已选择 B 方案；本规格待确认，正式页尚未实施。

## 目标与范围

将本地 A/B 原型中选定的 B 方案接入现有艺术史正式页面，独立页面和首页内嵌页面使用同一逻辑。颜色辅助识别当前学习范围，不增加新的地图导航功能，不表示历史疆界或整块区域都有作品。

选择依据：固定全图配色便于认地理；B 方案在保留同一套地理色彩的同时，更突出当前 Unit。用户选择 B，因此正式版不加入 A/B 切换器，也不保留原型的快捷 Unit 按钮和说明面板。

## 明暗与状态规则

1. 分区色相永久固定：亚洲金黄 `#d9a441`、欧洲蓝 `#6f9bc7`、非洲赭红 `#c9714f`、美洲粉 `#e0949a`、中东绿 `#8fa878`；太平洋／大洋洲使用原型补充的柔和紫 `#a597bd`。
2. 相关分区透明度为 0.72，其他分区为 0.12。淡化时仍保留原来的色相，例如欧洲始终是蓝色系，不会随 Unit 改成其他颜色。
3. “全部 Unit”显示当前可见作品涉及的所有分区；选择 Unit 后突出该 Unit 涉及的分区。点击 Unit 气泡进入其下级导航时，也使用该 Unit 的范围。
4. 时期、作品类型、传统和搜索筛选继续生效；高亮与当前筛选后的作品保持一致。零结果时所有已分组区域淡化，不保留上一次的高亮。
5. 只对地理大区着色，不扩展为逐国选中、文化疆域或历史国界。地图上的地区名称、作品编号和现有结果数量继续提供文字信息，颜色不是唯一识别方式。
6. 地点未确认的 AP230、AP241 不单独触发任何分区高亮，也不新增地理点位；它们已有的学习入口和计数保持不变。
7. 现有底图未分组且未明确补充分组的陆地保持原底色；南极不参与高亮。太平洋／大洋洲使用明确列出的既有陆地形状，不将原型的包围盒猜测当作正式分类算法。

## 实现边界

- 在原生艺术史渲染流程中，使用既有作品地区标签和当前导航状态计算相关分区集合，再更新底图路径的颜色／透明度；不使用作品的示意坐标反推国家。
- 地区标签到地理大区的映射为显式配置，支持跨区标签对应多个大区；对所有现有作品标签进行覆盖测试。未知标签不猜测归属，保留淡化并在开发校验中报告。
- 分区色彩更新与现有筛选渲染同步；纯缩放、平移不改变高亮范围，也不重复执行昂贵的地理计算。
- 仅修改底图的装饰性填色逻辑。保持现有底图点击穿透规则，颜色层不能截获气泡、缩放、平移或触摸事件。
- 不增加正式版工具栏行或图例模块；沿用已有 Unit／地区标签解释当前学习范围，避免改变工具栏和卡片布局。

## 必须保留的内容与交互

- 所有字体、字号、粗细、气泡尺寸、地图画布高度和响应式断点。
- 250 件作品及全部来源、图片、许可、学习内容、比较关系和坐标。
- Unit → 地区 → 地点 → 作品的导航、筛选、搜索、手动缩放／平移和复位。
- 大图弹窗可视区域、键盘焦点、关闭后焦点返回，以及已修复的首页地图高度清理逻辑。
- 世界史地图及其功能不变；不修改世界史配色或页面数据。

## 验收

1. 纯逻辑测试覆盖 U1–U10、全部 Unit、跨区标签、零结果和未确认地点；每次切换后不存在残留高亮。
2. 使用浏览器检查真正绘制后的颜色和透明度，而非只检查属性；确认切换 Unit 和筛选会更新颜色，缩放／平移保持原有行为。
3. 桌面和手机分别检查独立页与首页内嵌页；验证地图高度、文字与气泡尺寸不变，无水平溢出或控制台错误。
4. 验证作品／许可数据未改变、严格 250 件数据校验通过，并运行相关艺术史及世界史／首页回归。
5. 实施后提供本地正式页供查看；未取得新的明确请求前，不推送 GitHub、不合并 main、不复制 Desktop。

## 自检

本规格只确定装饰性分区高亮，没有新增筛选模式或国家选择功能。固定色相与低透明度淡化不冲突；全部 Unit 和零结果各有明确行为；未知地点不获得虚构位置。原型与正式版的差别已明确：正式版保留同色淡化，不保留原型外壳，太平洋形状改用显式分类。
